# 🔥 1. `useRef + useEffect` (Advanced Patterns)

---

## 🧠 Problem: Stale State in `useEffect`

### ❌ Issue

```js
useEffect(() => {
  setInterval(() => {
    console.log(count); // ❌ always old value
  }, 1000);
}, []);
```

👉 Why?

* `useEffect([])` runs once
* It captures **initial value of `count`**
* This is called **stale closure**

---

## ✅ Solution: useRef to store latest value

```js id="staleFixRef"
const Demo = () => {
  const [count, setCount] = useState(0);
  const countRef = useRef(count);

  // keep ref updated
  useEffect(() => {
    countRef.current = count;
  }, [count]);

  // interval uses ref (always latest)
  useEffect(() => {
    const interval = setInterval(() => {
      console.log("Latest count:", countRef.current);
    }, 1000);

    return () => clearInterval(interval);
  }, []);

  return (
    <TouchableOpacity onPress={() => setCount(count + 1)}>
      <Text>{count}</Text>
    </TouchableOpacity>
  );
};
```

---

## 🎯 Key Insight

```text
useRef solves stale closure problem
```

# 📱 2. Mini Project: Input Focus + Timer (Real App)

---

## ✅ Features:

* Focus input using `useRef`
* Start/Stop timer using `useEffect`
* Store interval ID using `useRef`

---

## 💻 Full Code

```js id="focusTimerApp"
import React, { useEffect, useRef, useState } from "react";
import { View, Text, TextInput, TouchableOpacity } from "react-native";

export const FocusTimerApp = () => {
  const inputRef = useRef(null);
  const timerRef = useRef(null);

  const [time, setTime] = useState(0);
  const [running, setRunning] = useState(false);

  // focus input
  const focusInput = () => {
    inputRef.current.focus();
  };

  // start timer
  const startTimer = () => {
    if (!running) {
      setRunning(true);
    }
  };

  // stop timer
  const stopTimer = () => {
    setRunning(false);
  };

  // effect for timer
  useEffect(() => {
    if (running) {
      timerRef.current = setInterval(() => {
        setTime(prev => prev + 1);
      }, 1000);
    }

    return () => {
      clearInterval(timerRef.current);
    };
  }, [running]);

  return (
    <View style={{ padding: 20 }}>

      <TextInput
        ref={inputRef}
        placeholder="Type here"
        style={{ borderWidth: 1, marginBottom: 10 }}
      />

      <TouchableOpacity onPress={focusInput}>
        <Text>Focus Input</Text>
      </TouchableOpacity>

      <Text>Timer: {time}</Text>

      <TouchableOpacity onPress={startTimer}>
        <Text>Start</Text>
      </TouchableOpacity>

      <TouchableOpacity onPress={stopTimer}>
        <Text>Stop</Text>
      </TouchableOpacity>

    </View>
  );
};
```

---

## 🧠 What You Learned

* `useRef` → store interval ID
* `useEffect` → manage timer lifecycle
* Cleanup prevents memory leaks
* Focus input via ref

# ⚡ 3. Performance Hooks: `useMemo` & `useCallback`

---

# 🔹 A. `useMemo` (Memoize Value)

---

## 📌 Problem: Expensive Calculation Runs Every Render

```js
const result = expensiveFunction(num);
```

👉 Runs on every render ❌

---

## ✅ Solution: useMemo

```js id="useMemoExample"
const result = useMemo(() => {
  console.log("Calculating...");
  return num * 2;
}, [num]);
```

---

## 🎯 Rule

```text
useMemo → memoizes VALUE
```

---

## 🔥 Example

```js
const [count, setCount] = useState(0);
const [num, setNum] = useState(5);

const double = useMemo(() => {
  console.log("Heavy calculation");
  return num * 2;
}, [num]);
```

👉 Changing `count` will NOT recalculate `double`

---

# 🔹 B. `useCallback` (Memoize Function)

---

## 📌 Problem: Function recreated every render

```js
const handleClick = () => {};
```

👉 New function each render ❌

---

## ✅ Solution

```js id="useCallbackExample"
const handleClick = useCallback(() => {
  console.log("Clicked");
}, []);
```

---

## 🎯 Rule

```text
useCallback → memoizes FUNCTION
```

---

# 🔥 Real Example

```js
const Child = React.memo(({ onClick }) => {
  console.log("Child Rendered");
  return <Text onPress={onClick}>Click</Text>;
});

const Parent = () => {
  const [count, setCount] = useState(0);

  const handleClick = useCallback(() => {
    console.log("Clicked");
  }, []);

  return (
    <>
      <Text>{count}</Text>
      <Child onClick={handleClick} />
    </>
  );
};
```

---

## 🧠 What Happens

Without `useCallback`:

```text
Parent re-render → new function → Child re-render ❌
```

With `useCallback`:

```text
Same function → Child does NOT re-render ✅
```

---

# ⚠️ When NOT to Use Them

❌ Don’t overuse
❌ Only use for performance bottlenecks

---

# 🎯 Final Comparison

| Hook        | Purpose                            |
| ----------- | ---------------------------------- |
| useRef      | Store mutable value (no re-render) |
| useEffect   | Side effects                       |
| useMemo     | Cache value                        |
| useCallback | Cache function                     |

---

# 🧠 Ultimate Memory Trick

```text
useRef → store
useEffect → side effects
useMemo → value optimization
useCallback → function optimization
```
